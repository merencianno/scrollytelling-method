# Estudos de caso

Um arquivo por aplicação da skill, escrito ao fechar a peça pela companheira
`companions/estudo-de-caso/` no modelo [`_modelo.md`](_modelo.md). É o que faz
a próxima peça começar melhor: cada regra de método que nasce aqui vira uma
mudança proposta para a skill (uma issue, ou uma entrada num `BACKLOG.md` que
você mantenha) e, aceita pelo dono, entra na skill e no
[`CHANGELOG.md`](../CHANGELOG.md).

Esta cópia da skill sai com o índice vazio: os estudos são de quem aplica.
