# NN — <Função narrativa> · "<conceito nomeável em uma frase>"

<!-- Arquivo: <projeto>/dv/secoes/NN-slug/prompt-vK-NN.md — K = geração do prompt, NN = seção.
     O cliente precisa saber qual é qual sem abrir o arquivo. -->

**Ato:** claro (<hex>) ou escuro (<hex>), conforme a blocagem.
**Elemento visual:** <qual anatomia real entra e o que ela diz da copy desta seção>.

## Double-check

- (a) Função — <a ideia sustenta a função narrativa da copy? por quê>
- (b) Nomeável e única — <cabe numa frase? repete o dispositivo de alguma vizinha?>
- (c) Fidelidade sem prova — <dá para desenhar em alta fidelidade sem rosto, número, depoimento?>
- (d) mantida | revista: <novo conceito> — <motivo em até 3 linhas. Manter é resultado válido.>

## Copy literal desta seção

> <a copy desta seção, literal, em blockquote — para o cliente ler ao lado da imagem;
> nunca para entrar na imagem>

## Prompt

```text
<PREFIXO COMUM DA DIREÇÃO VISUAL, COLADO SEM ALTERAR>

LAYOUT.
<A cena, coluna a coluna, de cima para baixo, com porcentagens de largura.
 O que é cada bloco de texto (headline de duas linhas, lista de quatro itens) — nunca a frase.
 Onde entra o mockup e o que ele mostra, nomeando a anatomia real.
 Onde estão os pontos da cor de ação, numerados ("accent #1", "accent #2"), no máximo três.
 Todo número é um traço; todo rosto é um círculo cinza; nada que a copy não diga.>
```

## Variações para testar

- <variação 1, uma linha>
- <variação 2, uma linha>

## Critério de aceite

- <o que a imagem precisa mostrar para valer como composição>
- <o dispositivo e o ato certos; o acento no lugar>
- <sempre terminar pelas proibições: cores vetadas; cor de ação em até três pontos; sem rosto; sem logotipo; todo número virou traço>
