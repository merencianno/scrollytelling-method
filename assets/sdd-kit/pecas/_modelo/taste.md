# Taste — <peca> (<cliente>)

Gosto **deste cliente**, capturado das falas do dono. Nasce vazio. Toda
regra leva um prefixo de escopo, o mesmo sistema de
`<caminho-da-skill>/references/taste.md`:

| Prefixo | Escopo |
|---|---|
| `[ofício]` | vale para qualquer peça, de qualquer cliente (vem das "Lições de ofício" do `taste.md` da skill) |
| `[casa]` | vale para todas as peças deste cliente |
| `[projeto]` | vale só para esta peça; nunca transporta sem perguntar |
| `[gosto]` | preferência do dono, ainda sem motivo claro; pode mudar amanhã — observar antes de generalizar |

Veto leva o motivo ao lado e a citação literal do dono. Nada herdado de outro
projeto entra aqui sem o prefixo `[ofício]`.
