# Changelog

Versão semântica: **maior** quando muda a ordem dos passos ou um portão;
**menor** quando entra passo, nível, referência ou companheira; **correção**
quando o texto se corrige sem mudar o método. Cada entrada diz o que mudou e,
quando houver, o estudo de caso de onde veio.

## 1.0.0 — 2026-10-01

Primeira versão numerada.

- **Níveis de visualização N1–N5**, escolhidos no Passo 0, antes das ideias
  (`references/niveis-de-visualizacao.md`): N1 ASCII · **N2 + prompt descritivo,
  o padrão mínimo, gerado ou não** · N3 + imagem gerada · N4 + prompts de asset
  por seção (`assets/prompt-asset-template.md`) · N5 + seção vídeo → frames →
  scroll (`references/video-frames-scroll.md`, mapeado, não testado).
- **N2 para no prompt**: o portão 2 pode recair sobre a descrição; o código
  parte dela (`imagem-conceito.md`, lição do primeiro N2).
- **`assets-gerados.md`** passa a admitir asset gerado em N4/N5; persona
  fictícia em ação é permitida, rosto de pessoa real só a partir de foto real.
- **Núcleo humano explícito** no Passo 1: blocagem + copy + ideia visual juntas.
- **Estudo de caso ao fechar** cada aplicação: companheira
  `companions/estudo-de-caso/` (`scrollytelling-estudo-de-caso`) e
  `estudos-de-caso/` com modelo e índice; cada regra de método nova vira
  mudança proposta para a skill.
- `projeto.md`, direção, blocagem, `secoes/README.md` do kit,
  `ideias-ascii.md`, `GUIA-IMAGENS.md`, `INICIAR-PROJETO.md` e checklist
  ganham o nível e o estudo de caso.
- Em aberto: a direção visual ensinável por escrito (hoje nasce de conversa
  com o dono).
